# TEBAK-JOKES-BAPAK-BAPAK-DUO
Tebak Jokes Bapak-Bapak Duo adalah game kuis tebak-tebakan lucu dan humor receh khas bapak-bapak yang dirancang khusus untuk dimainkan oleh 2 orang dalam 1 komputer / laptop. Game ini menggabungkan tebakan plesetan garing dengan mekanisme adu cepat, adu gengsi, dan poin stealing.
